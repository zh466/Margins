# Поля

Поля — настольная учебная доска для Windows. Запустите `Polya.exe` и выберите предмет. На странице предмета можно открыть недавний файл, выбрать другой файл с компьютера, открыть пример или начать новую тетрадь.

## Работа с доской

- Кнопка меню в левом верхнем углу открывает команды доски и пункт «К предметам». Кнопка справа сверху открывает список досок в текущей тетради.
- Основные инструменты находятся в плавающем ряду над холстом. Замок или клавиша Q оставляет инструмент активным. Меню «···» открывает ссылку и переключатель «Ровные фигуры».
- Свойства активного инструмента или выбранного объекта появляются слева. Для фигур доступны обводка, заливка, толщина, тип штриха и непрозрачность. Слева сверху можно настроить фон, а слева снизу находятся масштаб и история. Двойным щелчком можно изменить карточку или открыть предпросмотр ссылки.
- Фиолетовая кнопка внизу справа раскрывает учебные инструменты текущего предмета. Наведите курсор на значок, чтобы увидеть название. Геометрия включает библиотеку планиметрии и стереометрии. Щёлкните по чертежу, чтобы добавить его на холст.
- Зажмите ластик и проведите по объектам, которые хотите удалить. Ctrl+Z отменяет весь взмах. «Ровные фигуры» распознают от руки окружности и прямые отрезки. Удерживайте Shift при рисовании, чтобы зафиксировать пропорции фигуры или угол с шагом 45°.
- Колесо меняет масштаб вокруг курсора. Пробел с перетаскиванием перемещает холст. Клавиша 0 показывает всю доску, F1 открывает список горячих клавиш.

## Файлы и Google Drive

Ctrl+S сохраняет текущую тетрадь вместе со всеми досками в один файл `.polya`. Ctrl+O открывает такой файл. Изменения также записываются в локальную копию для восстановления сеанса.

Чтобы синхронизировать тетрадь, установите Google Диск для компьютеров, войдите в свой аккаунт и сохраните файл в папку «Мой диск» через меню «Сохранение в Google Drive». Можно также сохранить файл на ПК и загрузить его через веб-версию Google Drive. [Инструкция Google](https://support.google.com/drive/answer/10838124?co=GENIE.Platform%3DDesktop&hl=ru)

## Проведение урока

- Откройте «Урок → Шаблон урока». Предметный пример добавится отдельной доской в текущую тетрадь. В нём три кадра с разминкой, объяснением и практикой.
- В режиме редактирования двойной щелчок по карточке раскрывает или скрывает ответ. Кнопка редактирования в свойствах карточки открывает условие и ответ.
- F5 запускает показ. Стрелки переключают кадры, Enter раскрывает ответ, Esc возвращает к редактированию. В графике с `a` параметр можно менять во время показа.
- «Урок → Таймер задания» запускает отсчёт, который виден в обычном режиме и во время показа.
- Через «··· → Вставить изображение» добавьте PNG или JPEG с заданием. Изображение сохраняется внутри `.polya`, поверх него можно рисовать.

## Чертежи и электрические схемы

- Выберите чертёж на доске и перетащите видимую точку. Shift привязывает положение к шагу сетки чертежа. «Подписи» и «Замеры» управляют обозначениями, углами и другими доступными величинами.
- «Правка» открывает поворот, изменение размера и восстановление исходных точек. В стереометрии редактируются проекции.
- Дважды щёлкните по электрической схеме. Для вставки выберите тип детали вверху и нажмите «+» на нужном проводе. Чтобы изменить номинал, ветвь, положение или состояние, щёлкните по установленной детали. Щелчок по батарее открывает напряжение источника. Замеры показывают расчёт для идеального постоянного тока.
- У вставленного PNG или JPEG кнопка «Убрать белый фон» делает светлые участки прозрачными. «Вернуть фон» восстанавливает исходное изображение.

## Сборка

Исходники написаны на C# и используют WinForms из .NET Framework. Распакуйте архив и запустите в Windows PowerShell:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1
```

Файл `Polya.exe` появится рядом с исходниками.

На больших досках готовые участки холста переиспользуются между кадрами. При первом открытии и после смены масштаба резкие участки готовятся по очереди. Рисование, ластик и выделение остаются интерактивными во время подготовки. Формат тетрадей остаётся `.polya`.

Сетка сохраняет точное положение при зуме. При переходе между крупностью клеток линии плавно ослабевают и появляются.

В сборку входят Assistant и Source Sans 3. Лицензии шрифтов находятся в файлах `Assistant-OFL.txt` и `SourceSans3-OFL.txt`.
